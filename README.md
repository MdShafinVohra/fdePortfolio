## Local Development

Open `index.html` in a browser, or serve via any static HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This site is deployed on **GitHub Pages** from the `main` branch. After pushing
to the repository, GitHub Pages will automatically build and publish the site.
